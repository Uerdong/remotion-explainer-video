# 中文科普动画（Remotion 全流程）

按顺序执行十步。每步的产物都是下一步的输入，禁止跳步后回补。

## 十条铁律

1. **时长由配音决定，不由文案决定。** 参考文案只是意图，先按实测语速（中文 TTS 约 3.3 字/秒）估算总长；超目标时长就压字并改口语，再逐段合成、逐段量真实时长。
2. **BPM 必须实测，不采信用户或参考稿给的数字。** librosa 常把 104 BPM 报成 51.7（劈半），必须用自相关或换 onset 参数独立复核，取与听感一致的一档。
3. **所有切点吸附重拍。** 段落边界 = 该段配音结束时刻向上吸附到最近重拍；帧号 = `round(beat * (60/BPM) * FPS)`，写死进代码，不运行时计算。
4. **确定性渲染。** 禁 `Date.now()`、`Math.random()`；一切摆动用 `Math.sin(frame)` 推导；同一帧任意次渲染必须像素一致。
5. **时间轴单一事实源。** 段落、帧号、配音偏移、SFX 钉帧只存在一个 `timeline.ts`；改文案字数 → 重跑生成脚本 → 同步 TS，绝不手改两处。
6. **字幕断行按标点装箱。** 先按 `，；：。` 切 clause 再装箱；行宽用固定像素容器（如 `width: 1460` + `whiteSpace: "pre"`），禁止靠 `maxWidth` 让内容反推容器。
7. **音频三层分离**：BGM、人声、音效各自独立电平；人声 0.8、BGM 0.24 起步，渲染后实测峰值，>0.95 即削波风险。
8. **每镜头渲静帧自检。** 用 `npx remotion still` 逐帧看构图，成图前不看就渲全片等于返工。
9. **Windows 三个硬约束**：`--props` 必须传文件（`--props=props-nobgm.json`），内联 JSON 会被 shell 剥引号；ffmpeg 9 用 `-fps_mode passthrough` 而非 `-vsync`；改 TSX 后样式不生效先删 `node_modules\.cache`。
10. **先交付，再评价。** 已渲染的成片与已生成的图先原样交付给用户，问题只记录并说清，不擅自重生。

## 十步流水线

| # | 步骤 | 关键动作 | 产物 |
|---|---|---|---|
| 1 | 选题拆解 | 定知识点链条、目标时长、画幅、受众语气 | 一句话选题 + 时长/画幅约定 |
| 2 | 解说文案 | 按"钩子→模型→推导→结论→启示"压缩到目标字数，改口语 | 分段文案（6 段左右，每段 50–70 字） |
| 3 | 配音 | 逐段独立合成，同一音色同一参数；量每段真实时长与 f0 | `s1..sn.wav` + 段落时长表 |
| 4 | 字幕 | 由段时长生成 SRT，与画面切点同源 | `subtitles.srt` |
| 5 | BGM | 选曲或自合成，实测 BPM 与重拍表；不合适就换 | `bgm.wav` + `bgm.json`（beats_sec） |
| 6 | 重排时间轴 | 段落边界吸附重拍，算总帧数 | `timeline.json` + `timeline.ts` |
| 7 | 音效 | 关键动作逐一对应音色，代码合成，钉在重拍 | `sfx/*.wav` + 钉帧表 |
| 8 | 画面工程 | theme / components / timeline + 逐段场景组件 | Remotion 工程 |
| 9 | 自检渲染 | 逐段静帧 → 全片 → 实测峰值 | `out/*.mp4`、QA 静帧 |
| 10 | 发布物料 | 封面（代码渲染或设计工具）、标题、简介、话题 | 封面图 + `发布文案.md` |

## 冲突处理决策

| 冲突 | 处理 |
|---|---|
| 文案字数与目标时长冲突 | **压文案，不改时长**。压缩比 > 1.3 时改成口语短句，保留全部知识点 |
| 用户给的 BPM / 时长与实测不符 | **按实测做，并主动告知差异**（如"规范写 110 BPM / 58s，实测 104 BPM / 53.65s"），另给一条"是否按规范重排"的选项 |
| 用户指定曲目风格不匹配 | 先实测该曲的 BPM / 频谱 / 峰值并给数据，再自合成替代，**交付时披露偏离原因** |
| 参考视觉规范与封面或平台风格冲突 | 两件事分开：正文沿用用户的视觉规范，封面按封面平台的传播逻辑做，并说明取舍 |

## 交付清单

- 成片双版本：带 BGM / 无 BGM（平台自带曲库时用后者），同帧数同时长
- 字幕 SRT（可外挂，与画面内嵌一致）
- 交付说明：成片表、BPM 与节拍口径、段落边界表、重拍落点表、文案、音效表、混音电平、工程结构、运行命令
- 封面（横版 + 目标平台竖版）、标题多档、简介多版、话题标签
